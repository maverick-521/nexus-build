A site assistant that only says what the site says.

I built this to show how an FAQ chatbot for a small business can work. It answers questions about my own studio, Nexus Studio, using only the text on the Nexus site: services, starting prices, turnaround, process and FAQs. It isn’t client work.

How it works

  • Grounded in real content. A build script reads the site’s HTML and turns each service, FAQ and process step into a small knowledge chunk. Answers are copied from those chunks, with a link to the section they came from.
  • No API key, no server. A small BM25 keyword search runs in your browser. Nothing you type is sent anywhere or stored.
  • Says when it doesn’t know. If a question isn’t covered on the site, it says so and offers a “Get in touch” handover to a person instead of guessing.
  • Honest about being a bot. It never claims to be human.
  • Drop-in. The same widget works as a floating button on any site with one script tag. It’s keyboard-accessible, works on mobile and respects reduced motion.

For a client, the same approach can be extended with an LLM to write answers from their documents, while keeping sources and a human handover. This demo deliberately uses no AI model, so it can’t make anything up.
