Process

Four steps. No surprises.

  1. 01

    Scope chat

    A short call or message thread. You tell us the outcome you want; we ask the questions that matter.

  2. 02

    Written quote

    Scope, price and a realistic timeline in writing, before any work starts.

  3. 03

    Build in the open

    Small, working pieces and regular updates, so you see it running early.

  4. 04

    Hand over

    Source code, setup notes and a walkthrough, so it keeps running without us.
